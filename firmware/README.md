# Nickey44A firmware

配布用ファームウェアをバージョンごとに保管しています。最新版は
[v1.1.0](v1.1.0/) です。各バージョンに含まれるファイル名は共通です。

## バージョン一覧

| バージョン | 概要 |
| --- | --- |
| [v1.1.0](v1.1.0/) | ディープスリープへの移行時間を1時間から2時間に延長。その他の変更はありません。 |
| [v1.0.0](v1.0.0/) | 初回リリース。Nickey44A の左右それぞれに対応したファームウェアと、設定リセット用ファームウェアを収録。 |

新しいバージョンを追加する際は、この表にバージョン番号と主な変更内容を追記してください。

## ファイル一覧

各バージョンのフォルダーには、以下のファイルが含まれます。

| ファイル | 書き込む側 | 用途 |
| --- | --- | --- |
| `nickey44a_l.uf2` | 左手側 | 左手側キーボード用ファームウェア |
| `nickey44a_r.uf2` | 右手側 | 右手側キーボード用ファームウェア |
| `settings_reset.uf2` | 左右それぞれ | Bluetooth のペアリング情報などを初期化する設定リセット用ファームウェア |

通常は、左右のキーボードをブートローダーモードにして、それぞれ対応する
`.uf2` ファイルを書き込んでください。ペアリングの不調や設定を初期化したい場合は、
先に左右両方へ `settings_reset.uf2` を書き込み、その後で左右それぞれの通常ファームウェアを
書き込みます。

詳しい書き込み手順は、[Firmwareの書き込み方法](https://nixiy.github.io/nickey-docs/guides/firmware/)
を参照してください。
